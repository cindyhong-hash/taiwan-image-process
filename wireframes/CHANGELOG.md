## 詳細變更（按討論輪次）

### 第 1 輪 — 結構大改（9 項）
1. **側邊欄**：撳入品牌唔再喺側欄展開「廣告活動圖／風格組件／連動帳號／品牌設定」4 項；改喺右邊內容區頂部切換。
2. **合併**：③ 統一側邊欄 與 ④ 權限合併成一節。
3. **新增按鈕合一**：「新增圖片」＋「新增素材」→「新增產品／素材圖片」。
4. **拎走圖庫／積木區**（風格組件入面嗰行「圖庫 226 · 積木 63 · 構圖/配色/語氣/背景」）。
5. **取消廣告活動圖分類**：因為廣告活動圖嘅儲存改為「參考圖」（圖庫分類更新，參考圖數量 +14）。
6. **新增表單**：拎走行業範本；文字積木拎走「語氣」（剩構圖/配色/背景）；尺寸同數量改成俾用戶自己揀（selection）。
7. **素材＋圖片融合**：變成一個表單、4 種類型（產品圖／背景／人像／2D 插圖）。
8. **連動擺登入下**：原第九部分連動擺喺登入之後（當時保留畫面 2 + 版本 B 兩款）。
9. **取消第十部分**（撳入廣告活動圖 asset）；⑪⑫ 對照表各拎走「廣告活動圖」選項。

### 第 2 輪 — 由 PDF 新增「品牌接駁」章節
- 根據提供嘅 3 頁 PDF（深色稿），用我哋淺色風格重畫成新章節，插喺品牌設定同廣告活動圖之間：
  - **畫面 1 引導式接駁**（新品牌空狀態 + 一鍵接駁 IG/FB/Shopify）
  - **畫面 2 AI 風格 DNA 掃描中**（非同步進度 65% + checklist）
  - **畫面 3 常駐品牌記憶工作區**（AI 已學習品牌記憶 + 風格禁忌 NEGATIVE PROMPTS + 活動列表）
- 強調：唔直接 copy PDF 圖，而係跟返我哋既有 design tokens 重畫。

### 第 3 輪 — 連動收納 + 設定頁 + 細節
- **新增「品牌設定」頁**：入面 2 個 switch tab（修改品牌設定 / 連動帳號調整），連動帳號正式收喺度。
- **移除獨立「連動帳號」nav**：側欄 selector 由 4 項減到 3 項；風格組件 tab bar 拎走連動帳號，改喺右上角加「設定」掣（廣告活動圖頁亦加）。
- **新增表單**：產品圖恢復「主體（二選一）：上傳產品主圖 / 輸入文字（文字主體）」；自訂尺寸加註「按 IP 記低」。

### 第 4 輪 — 換品牌 + 流程圖 + List View
- **畫面 1/3 換返我哋品牌**（舒適牌 Lady's Talk / S Bar By SOCIE），拎走 Wonder／迪卡儂／點子實驗室。
- **登入版本 B 保留**（當時）。
- **② 流程圖重畫**：反映連動收入設定、廣告活動圖 List 屬同事、成品入參考圖、新增掣合一。
- **品牌設定固定右上角**（檢查並統一各頁）。
- **⑥ 廣告活動圖 List View 拎走**：List 由同事設計，呢邊只保留撳入詳情。
- **⑦ 風格組件兩個掣移右**：分類 chips（左）與動作掣（右）左右分開、中間留空。

### 第 5 輪 — 順 flow + 一致化
- **重排整體 flow**：品牌設定由前面移到功能頁之後（onboarding → 功能 → 設定 → 附錄）。
- **拎走登入版本 B**：因為已收喺品牌設定 Tab 2，避免重複。
- **側邊欄一致化**：③ 右側 mockup 改成同真實頁面一致嘅 header（廣告活動圖／風格組件 switch tab 喺左、品牌設定固定右上）。
- **排版一致**：所有 header 動作 + 品牌設定 統一擺右上角，主要「新增」永遠最右。

### 第 6 輪 — 按鈕系統升級（統一 size + radius）
- 新增 CSS class `.hbtn` / `.hbtn-primary` / `.hbtn-dark`，統一全部 header 動作按鈕嘅 size、padding、radius（radius 10、min-height 38、padding 8×15、font 13）。
- 套用範圍：③ 側欄 ×2、④ 畫面1 + 畫面3、⑤、⑥ —— 共 7 個位，全部一致。
- **畫面 5 重做**：拎走「撳入詳情」（候選圖 + 框選改善 + 文案），改成將品牌記憶工作區嘅「舒適牌」拉大成完整頁 + 加 switch tab（廣告活動圖／風格組件）。⑤ 與 ⑥ 變成同一工作區嘅兩個對稱 tab。
