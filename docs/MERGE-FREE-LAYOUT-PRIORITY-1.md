# 自由排版 Priority 1 合併說明

## 分支與範圍

- 分支：`codex/free-layout-priority-1`
- 基底：`feat/magic-layers-v2`（commit `4ba70d1`）
- 原則：不更動資料庫 schema；效果跟著既有 `SavedLayer.fx` JSON 儲存，舊資料可直接讀取。

## 已完成

- 可編輯文字新增「一般、向上弧形、向下弧形、波浪」四種路徑。
- 弧度可調 5–100%；波浪可調 1–5 個週期。
- 支援既有漸層、外框、陰影、斜體與字距。
- 預覽、復原／重做、草稿儲存及 PNG 匯出共用同一渲染邏輯。

### 擴圖／改尺寸（commit 2）

- 目標比例：1:1、4:5、9:16、16:9。
- 擴展方向：自動置中、左、右、上、下。
- 模式：保留主體位置、自動重新構圖。
- 一次生成 2–4 個候選版本，選定後才加入畫布。
- AI 擴展結果放在最底層；原有圖層保持獨立並依新畫布位移，可復原、隱藏或刪除。
- API 獨立在 `src/app/api/magic-layers/outpaint/route.ts`，沿用既有 `inpaintImageFal()`，沒有複製供應商設定。

### 對齊與智慧參考線

- 拖曳時吸附畫布邊緣、水平／垂直中心、其他可見物件的邊緣與中心、自訂參考線。
- 吸附時顯示洋紅對齊線與相對畫布的 px 距離。
- 內建三分法、九宮格、8px 基線、貼文安全區、Reels 安全區；僅供編輯，不會輸出。
- 可輸入畫布百分比新增水平／垂直自訂參考線。
- 選取物件可一鍵畫布置中；至少三個可見且未鎖定的非背景圖層可水平／垂直平均分布。
- 不增加套件或資料庫欄位，自訂參考線目前屬單次編輯工作階段狀態。

## 新版合併方式

優先 cherry-pick 本分支提交。若新版同時修改 `MagicLayersEditor.tsx`，手動搬移三個獨立區塊即可：

1. `TextFx` 的 `warp / warpAmount / waveCount` 欄位。
2. 右側文字設定面板的「文字路徑」控制。
3. `drawWarpedText()` 及 `drawTextEl()` 的分派。

不需要 migration，也不依賴新套件。舊版沒有 `warp` 時會自動使用一般直線文字。

## 下一段 Priority 1

局部 AI 改圖應沿用現有 `/api/inpaint` 與 `fal.ts`，只新增自由排版的遮罩 UI；避免複製供應商呼叫。圖層與復原基礎已存在，群組功能應新增 `groupId` 到 SavedLayer JSON，不需更動資料庫欄位。
