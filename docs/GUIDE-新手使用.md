# 使用指南 — 社群行銷素材工具

> ⚠️ 重要流程：**要先建立「品牌 / 客戶」，先可以入素材庫做生成。**

---

## 🚀 第一次安裝（Setup）

### 1. 前置需求
- [Node.js 20+](https://nodejs.org/)
- npm（隨 Node.js 附帶）

### 2. Clone 專案
```bash
git clone ssh://git@ssh.github.com:443/verna-fimmickTW/market-tool-demo.git
cd market-tool-demo
```

### 3. 設定 API Keys
```bash
cp .env.example .env.local
```
打開 `.env.local`，填入以下必要 keys：

| 變數 | 用途 | 取得位置 |
|---|---|---|
| `OPENROUTER_API_KEY` | 文案生成 + 圖片分析 | [openrouter.ai/keys](https://openrouter.ai/keys) |
| `FAL_KEY` | 圖片生成 + 產品合成（主力）| [fal.ai/dashboard/keys](https://fal.ai/dashboard/keys) |
| `HF_TOKEN` | 圖片生成備用 | [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)（建 Read token）|

### 4. 安裝 + 建立資料庫
```bash
npm install
npx dotenv -e .env.local -- npx prisma db push
npx dotenv -e .env.local -- npx prisma generate
```

### 5. 啟動
```bash
npm run dev
```
開瀏覽器去 **http://localhost:3000**，就可以開始用。

## 0. 呢個工具用緊邊啲 AI（一覽）

| 功能 | 用緊邊個 AI |
|---|---|
| 產品圖合成（主力）| **FLUX.2 [pro] edit**（中文字保真最好）|
| 產品圖合成（其他選擇）| **nano-banana = Google Gemini 2.5 Flash Image**（最自然）/ **Seedream 4.5**（ByteDance）|
| 純文字生圖 / 背景 | **FLUX.1 [schnell]** |

| 自動去背 | **BiRefNet** |

## 操作順序（跟住一步步做）

### 步驟 1 — 建立品牌 / 客戶（**必須先做**）
- 左欄「客戶資料夾」→ 撳 **＋ 新增客戶**（或去 `/clients` 頁新增）。
- 填品牌資料（名稱、主色、語氣、禁忌字眼等）。
- 揀返個品牌入去 → 之後所有素材/生成都歸入呢個品牌。
- 🧠 AI：無（純設定）。

### 步驟 2 — 準備素材底（「風格組件」分頁）
> 呢步係俾生成「有嘢參考」。可揀做、亦可跳去步驟 3 直接生。
- **上傳參考圖**：上傳品牌舊廣告 → AI 自動抽出「構圖 / 配色 / 語氣」。🧠 **GPT-5.4 nano（讀圖）**。
- **素材生成**：分 **背景 / 人像 / 插畫** 三類，一次出 1–5 張揀；可填參考風格圖、可 ✨潤色描述。
  🧠 背景=**FLUX.1**、人像=**FLUX.2 pro**、插畫=**Recraft V3**；潤色=**GPT-4o mini**。

### 步驟 3 — 生成圖片（「生成圖片」分頁）

**(A) 產品圖合成【主菜】**
1. 主體揀 **產品圖（合成用原圖）** → 上傳產品圖（最多 3 件，**唔使自己去背**）。🧠 去背 **BiRefNet**；讀圖填主體 **GPT-5.4 nano**。
2.（可選）揀風格積木：構圖 / 配色 / 背景，或一鍵套行業範本。
3. 揀 **合成方式**：
   - **FLUX.2 edit · 主力** — 中文字最清晰（產品多過 1 張時細字可能微糊）。
   - **nano-banana** — 場景最自然（有字會糊，適合無產品文字嘅合成）。
   - **Seedream 4.5** — 多圖文字較好（偶有機率出錯字）。
4. **生成數量 1–5**：一次出多張，揀邊張先保留入圖庫。
5. 揀尺寸（正方 1200×1200 / 橫向 1800×1200）→ 撳 **合成**。
6. 完成 → 出圖 + **繁體中文文案**（主標/副標/CTA）🧠 **GPT-4o mini**。打開結果可睇「**來源產品圖**」、下載、調整、移到其他客戶。

**(B) 文字主體（AI 生成）+ ✨潤色**
1. 主體揀 **文字主體（AI 生成）** → 手寫短指令（例：「夏日防曬，海邊，清爽」）。
2. 撳 **✨潤色** → AI 擴寫成完整中文設計描述（可再改）。🧠 **GPT-4o mini**。
3. 撳生成 → 純 AI 場景圖 + 文案。🧠 生圖 **FLUX.1**、翻英 **GPT-4o mini**。

### 步驟 4 — 圖庫管理
- 圖庫 filter：📎參考圖 / 🌄背景 / 🧑人像 / 🎨插畫 / 🟣產品成圖；每張顯示尺寸 + **用咗邊個 AI 引擎**。
- 點圖 → 下載 / 調整 / **移到其他客戶或設公用** / 刪除。

---

## ⚠️ AI 限制（一定要知，唔係 bug）
1. **產品上中文字**：生成式合成會「重畫」標籤。**FLUX.2 edit 單圖保真最好**；多過 1 張產品時細字會微糊；nano-banana 會明顯走樣（適合無產品文字嘅圖）。
2. **源圖要高清**：源圖太細、出嚟一定糊（AI 加唔到原本冇嘅細節）。請用高清產品相。
3. **生成要錢／時間**：每次都 call 付費 AI，唔好亂試太多；偶有等候屬正常。

## 常見情況點揀
| 你想 | 點揀 |
|---|---|
| 產品擺入靚場景、中文字要清 | 合成方式：**FLUX.2 edit** |
| 場景最自然、產品無文字 | 合成方式：**nano-banana** |
| 一次出幾張揀靚嗰張 | 生成數量調 2–5 |
| 純氛圍圖、冇實物 | 文字主體（AI 生成）+ 潤色 |
| 要人像 / 插畫 / 純背景素材 | 風格組件 →「素材生成」|
